# How to Request Software Installation

## Standard software (no approval needed)
Common applications available in the Software Center:
- Microsoft Office suite
- Zoom, Teams, Slack
- PDF readers (Adobe Acrobat, Foxit)
- Common browsers (Chrome, Firefox, Edge)

**Steps:**
1. Open the Software Center on your workstation
2. Search for the application
3. Click "Install" — no admin rights needed

## Non-standard software (requires approval)
Applications not in the Software Center require manager approval and IT review:

1. **Submit a request** via the IT service portal
   - Application name and version
   - Business justification
   - License requirements (free, paid, volume license)
2. **Manager approval** — your manager will receive a notification
3. **IT security review** — IT checks for security vulnerabilities and compatibility
4. **Installation** — IT installs remotely or provides temporary admin rights

## Developer tools
For development tools (Docker, IDEs, compilers):
- Submit via the developer tools request form
- Temporary admin rights may be granted for 48 hours via PAM

## Important notes
- Never install software from unverified sources
- Pirated or unlicensed software is a security and compliance violation
- Some software may require a security assessment before approval

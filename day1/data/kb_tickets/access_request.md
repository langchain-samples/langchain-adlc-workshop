# Requesting Access to Systems and Facilities

## System access

### Standard access (available to all employees)
- Email, calendar, intranet
- Microsoft 365 apps
- VPN

### Department-specific access
- Submit a request via the IT service portal
- Specify the system, required access level, and business justification
- Manager approval required
- Access is granted on a least-privilege basis

### Privileged access (admin, root, database)
- Requires additional security review
- Time-limited access via PAM (Privileged Access Management)
- All actions are logged and audited

## Facility access

### Badge access
- New badges are issued by Security on your first day
- Report lost badges immediately to Security
- Temporary badges available at the front desk

### After-hours access
- Standard badge access: 07:00–19:00 weekdays
- After-hours access requires manager approval and Security notification

## Important notes
- Access reviews are conducted quarterly — unused access is revoked
- Never share your credentials or badge with others
- Report unauthorized access attempts to Security immediately
